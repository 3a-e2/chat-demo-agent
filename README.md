# chat-demo-agent

基于 `chat-demo` 深度二次开发，集成了 Linux 终端、AI Agent 智能调用、第三方 OpenAI 接口适配及优化 UI 的多功能AI助手。

## ✨ 核心功能

*   **Linux 终端**：内置命令行环境，支持直接执行命令。
*   **AI Agent**：支持自动化任务编排与多步智能调用。
*   **多接口适配**：完美兼容第三方 OpenAI 格式 API 及自定义接口。
*   **UI 升级**：重构界面，交互更现代、更流畅。

##  下载安装

* 直接下载 APK：点击上方文件列表中的 `deepseek-agent-2.0.0-release.apk`。
* 获取源码：点击上方文件列表下载 `source-code.zip`。
源码运行

解压源码后，在根目录执行：
npm install
npm run dev
